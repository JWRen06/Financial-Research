## 使用

每个文件夹包含 `paper.pdf`、`source/` 和 `reproduction/`。先读论文，再按该篇README安装依赖和运行；各篇采用的模型、信息条件和数值环境不同。

前三篇采用2026-10-31修订版；后续A、B采用2026-10-31重写版，C采用2026-11-01报价推广版。英文目录名用于定位；论文正文为中文，未将旧英文译稿混入当前版本。

所有实验均为合成或条件模型的计算核验。数值证书、一般证明和现实市场验证应分别理解；当前材料未宣称已通过外部同行评审。作者信息和开放许可证未擅自补写。
